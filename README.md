# 🌑 Lumio

> A modern social media platform built to connect people and share moments.

![Lumio Preview](./screenshots/social-preview.png)

---

## 📖 About

Lumio is a full stack social media application inspired by modern platforms like Instagram and Threads.  
The project focuses on building a clean, responsive and modern user experience while exploring real-world full stack development concepts.

This project was created to improve my skills in:

- Frontend architecture
- Backend APIs
- Authentication & authorization
- Database relationships
- Responsive UI design
- Full stack integration

---

## 🚀 Features

- 🔐 User authentication
- 📝 Create and delete posts
- ❤️ Like system
- 💬 Comments
- 👤 User profiles
- 🖼️ Image uploads
- 🌙 Modern dark UI
- 📱 Responsive design
- ⚡ Fast and interactive interface

---

## 🛠️ Tech Stack

### Frontend

- ⚛️ React / Next.js
- 🎨 Tailwind CSS
- 📦 React Query
- 🔥 TypeScript

### Backend

- 🟢 Node.js
- 🚏 Express
- 🔑 JWT Authentication

### Database

- 🐬 MySQL
